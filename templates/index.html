This system leverages a Random Forest classifier trained on 15,000 patient records across 11 clinical biomarkers — including glucose, HbA1c, BMI, blood pressure, and lifestyle factors — to classify patients into Healthy, Pre-Diabetic, or Diabetic with 80% accuracy.

🧬 11 Biomarkers 📊 3-Class Classification ⚡ 80% Accuracy 🔮 Random Forest 🌐 Flask REST API

About This Project

This AI-powered diabetes prediction system processes clinical measurements from routine health examinations. The Random Forest model was trained on 15,000 balanced patient records with class-weighted training to handle imbalance. It outputs one of three diagnostic classes — Healthy, Pre-Diabetic, or Diabetic — with probability scores for each class, enabling transparent clinical risk interpretation.
